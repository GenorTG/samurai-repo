# samurai-repo

Package repository (data only) for **Samurai OS** — an Arch-based personal distro.

- Channels: `[samurai]` (tag `x86_64`) and `[samurai-testing]` (tag `x86_64-testing`), published as
  GitHub Releases. `samurai.db` is uploaded last so clients never see a db naming missing packages.
- Fallback mirror: `https://repo.smart-samurai.pl/$repo/$arch`
- Packages are GPG-signed; fingerprint: `DFE8C148C042AA3C199AAEA08436E12731EDD3FA`
- Source, specs and CI: https://github.com/GenorTG/samurai-os
